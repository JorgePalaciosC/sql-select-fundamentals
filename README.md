¿Por qué es mala práctica usar SELECT * en producción? 
-Rendimiento(si una tabla contiene muchos datos la consulta puede tardar mucho tiempo)
-Seguridad(aumenta la posibilidad de exponer información que la aplicación no debería manejar)

¿Por qué son importantes los alias para un stakeholder no técnico? 
Es importante por que una persona que no entienda los términos de una tabla ya sea por que este en otro idioma o solo por sintaxis, el alias permite poner un nombre legible
